# 地圖鍛造師服務修正

- 點擊地圖鍛造師後，可選擇強化現有裝備／法寶，或委託打造新的裝備／法寶。
- 依鍛造師境界減免 50%–70% 靈石、鍛造石與天鑄玄晶；材料以整數向上取整。
- 強化成功率額外增加 15–25 個百分點，最高 100%；沿用品階上限、覺醒詞條與失敗保留機制。
- 委託成功率 85%–95%，每次委託傳說機率 15%–25%，其餘成功產出金品。兩個機率均以每次委託計算，畫面列出金品與失敗機率。
- 確認前顯示原價、優惠消耗和機率；支援指定目標等級的一鍵強化與最低／平均估價。
- 成功或失敗都扣除本次資源；成品滿包進未領取匣，傳說可在鈴鐺通知查看。
- 服務限定靠近對應地圖鍛造師使用；普通天工鍛造及三金合成沿用既有規則。
