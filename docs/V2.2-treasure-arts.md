# V2.2 法寶神通・動態詞條系統

## 最小修改方案與實作

既有基礎屬性、數值詞條、寶石及裝備實例維持原結構。新增 data/treasure-arts.js 的 60 種神通設定、systems/treasure-arts.js 的生成／遷移及寶石聯動、systems/treasure-arts-combat.js 的共用效果解譯器，以及 ui/treasure-arts.js 的戰鬥與詳情介面接線。

既有傷害入口、普通怪、異界首領、高境界敵技、魔修敵技均接入。沒有增加第二個計時器；沿用 stepEconomy，每個有效戰鬥幀執行一次。暫停及角色管理畫面不推進神通戰鬥時間。

## 保存及養成

每件法寶 specialArts 保存唯一神通 ID 列表；artsVersion/artsQuality 標記一次性遷移與升階補足。以實例 ID 的可重現種子補齊，重新讀檔不重抽。原有實例、屬性、強化、寶石、融合等級不重建。原始具名法寶亦可遷移。

白 0–1、藍 1–2、紫 2–4、金 4–6、傳說 6–8；原寶石孔規則不變。依飛劍、護盾、靈珠、仙鼎、通用類型限制候選池，部分高階神通要求元嬰以上。升階保留原神通並補足；同階等級合成保留主件。付費保留詞條的傳承一併轉移神通，來源移除已轉移神通。傳承會保留每件寶石。

## 戰鬥及上限

- 十二飛劍以世界座標飛行，目標死亡可重新尋敵，目標不足可重複分配；每支經過既有實際傷害結算。
- 常駐飛劍有存活時間與再次攻擊間隔，卸下或切圖會停止。
- 冰凍普通敵人最多 3 秒；首領最多 0.6 秒，之後免控 5 秒。所有移動、普攻、魔修及高階敵技均受凍結限制。
- 連鎖最多 6 名不同敵人，每跳乘 0.85，不從神通傷害重新觸發攻擊神通。
- 最多 72 支神通飛劍、12 個持續區域、80 筆視覺事件；每幀最多 32 次神通傷害。溢出效果略過。
- 護盾最多最大氣血 35%，神通減傷最多 50%、閃避最多 25%、控制抗性最多 75%。同名神通只採較強的一份，不因主選及出戰重複套用。
- 靈氣回流每次命中恢復最大真元 0.4%，CD 0.34 秒，最多每秒三次。恢復均限制於最大氣血／真元。
- 雷、冰、火、攻擊、生命、真元、防禦、修為寶石均有聯動；冰凍最多 3 秒、連鎖最多 6 目標。修為寶石聯動採出戰法寶中的最高加成，最高 30%。

## 資產

ComfyUI Qwen Image 2.1 生成來源圖，工作流程與原圖保存於 art/treasure-arts。60 個透明 ICON 各有 256 Master／64 Runtime。9 組特效各有透明來源與 16 幀 4×4 Sprite Sheet（每格 128，20 FPS），以生成圖做脈動動畫。asset_id、版本、雜湊、FPS、錨點與座標規格見 src/assets/treasure-arts/manifest.json。

## 驗證

單元與實際傷害入口整合測試包含十二飛劍、重新尋敵、冰凍時間／首領抗性、連鎖遞減／不遞迴、常駐效果停止、回血回靈、護盾減傷、同名不疊加、境界變更、舊檔遷移、生成結果保存、資產尺寸及效能容量上限。build 另檢查語法與資產完整性。

瀏覽器檢查 390×844、360×800 手機視窗：神通詳情可捲動、六孔寶石及操作按鈕可達、詞條庫六類篩選及組合預覽正常、無水平溢出及主循環錯誤。這是手機尺寸瀏覽器測試，未在實體手機上測得 FPS；尚不能聲稱實機效能已驗收。
