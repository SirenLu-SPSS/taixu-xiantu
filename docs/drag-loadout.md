# 人物欄拖移裝備／出戰

- 滑鼠可按住拖移；觸控／觸控筆停留約 300ms 啟動拖移。
- 按住前直接上下滑動會捲動背包或人物頁；拖移中靠近上下邊緣可自動捲動。
- 裝備只能拖到對應部位，例如頭冠到頭冠、武器到武器。境界、背包容量及來源狀態均在提交時重新檢查。
- 靈寵與法寶各八格：待命伙伴拖到空位即可出戰；拖到已佔用欄位替換原伙伴；兩個已出戰伙伴互拖交換順序。
- 伙伴排序沿用戰鬥使用的 companions.order/deployed，切換地圖、重新讀檔仍相同。空欄位放入時接續目前出戰順序。
- 裝備或出戰伙伴拖回背包，可卸下／休息。伙伴所有權、等級、強化、寶石、神通及冷卻保留。
- 背包只列待命伙伴，出戰伙伴不再重複出現；容量文字同時顯示待命及持有數。
- 不合法目標不改動任何資料；拖移時有合法欄位提示、當前目標高亮及結果訊息。Esc、取消觸控、失去焦點會取消操作。
- 保留原本點擊詳細資訊與按鈕操作。
