# 背包批次販售與未領取匣

- 入口：角色介面乾坤背包新增「售白品裝備」「售藍品裝備」「整理背包」，原收納匣改為「未領取匣」並顯示待領數量。
- 批次販售只處理背包指定品質裝備，不販售法寶、靈寵、丹藥或材料。鎖定、穿戴、強化 +1 以上與已鑲嵌物品均跳過。先顯示總件數／價格，確認時重新驗證清單；清單改變則重新確認。單件販售也檢查鎖定。
- 點物品詳細資訊可鎖定／解鎖，背包顯示鎖頭。舊式同 ID 堆疊物品鎖定整疊；新式唯一實例逐件鎖定。鎖定資料存於 bag.locked 與 instance.locked，舊物轉成鍛造實例時保留鎖定。
- 整理會合併可堆疊物品並依品質／名稱排列，不合併獨立裝備，不改變穿戴與屬性，保留未知物品。背包原有分類／名稱排序選項繼續可用。
- 原金品／傳說等新式掉落本已有 economy.mail 保護，本次補上普通怪與舊式 add() 掉落滿格存入相同信箱。滿格入匣立即存檔。商店購買仍會檢查容量、拒絕扣款；未完成的採集點因滿格不消耗採集冷卻，可騰空間後再採。
- 未領取匣沒有數量上限或到期刪除；跟隨版本 2 原存檔保留。開啟時領取可容納獎勵，仍滿格的保留並列出名稱／數量。修復舊物實例的領取與重複 grant 可能重複入匣問題。
- 96 項測試與建置通過，含精確品質販售、鎖定重載／轉換、整理數量守恆、滿包傳說保留與防重複領取；瀏覽器驗證鎖定與 3 件藍品出售獲得 180 靈石。

存檔沿用原資料結構，未清除 localStorage。未領取匣保存在目前瀏覽器的角色存檔，不是雲端跨裝置信箱。
