# 品階鍛造與覺醒詞條

傳說目前強化等級對應基礎成功率：+0 100%、+8 97.6%、+30 90%、+60 78%、+100 60%、+130 55%、+160 50%、+200 45%（+200 已達上限）。節點之間線性計算。白／藍／紫／金在各自上限附近約75%／70%／70%／65%。

輔助寶石一次消耗1顆，不論成功或失敗。1–6階基本增加3／5／8／12／17／22個百分點，再加寶石品階索引×1個百分點，最高實際成功率100%。只使用背包寶石，不使用鑲嵌中的寶石。材料或寶石不足、亂數無效、已達上限均不扣費。

傳說在30／60／100／130／160／200覺醒；金品在20／40／60／80覺醒。獨立詞條庫12條，金品可用7條，傳說可用12條。每件裝備不重複詞條ID，選取依實例ID與門檻穩定決定，重新整理不重抽。舊存檔已達門檻會補齊，保留原隨機詞條、孔位與強化數據。

靜態能力接入既有屬性與能力上限；範圍技能在命中時觸發真實傷害，6–8秒冷卻，每次命中總共最多額外3個目標，不遞迴觸發其他覺醒技能。技能庫含敵我適用標記、半徑、倍率、目標數及冷卻，供之後BOSS模組引用；本次未改動BOSS技能。
