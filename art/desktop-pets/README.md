# 電腦版靈寵展示美術

本機 ComfyUI Qwen Image 2.1 重繪 42 種靈寵：pet_0–11 與 v21_pet_0–29。每種工作流程保存於同目錄，含提示詞、模型、seed、768px 與 16 steps 參數。輸出轉 WebP quality 88。

PetShowcase.asset 管理種類對應與舊版狐、龜、鷹、龍的別名。桌面展示、清單與出戰欄縮圖使用相同圖片，不替換角色欄位及戰鬥素材。

動態效果由 CSS 呼吸縮放、底部靈氣圈與少量光點合成；不增加戰鬥特效或計時器，遵循 prefers-reduced-motion。培養、進化與其他操作呼叫既有詳情 UI 動作。
