# 技能介面美術與升級規則

35 張本機 ComfyUI Qwen Image 2.1 技能圖，包含普通攻擊、四種初始功法及 30 種高階卷書。768px、16 steps；工作流程保存於同目錄，WebP quality 88。技能列表、技能裝配與戰鬥技能圖示共用對應大圖。

初始功法上限 30 層；化神卷書 30、煉虛 40、合體 45、大乘 50、渡劫 60。寶石階級依卷書境界為 1–6 階；每次升級消耗靈石與對應類型寶石。大乘卷書金品、渡劫卷書傳說，傳說升級另耗 1–3 仙玉。
